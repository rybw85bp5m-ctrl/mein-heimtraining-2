MEIN HEIMTRAINING – INSTALLATION

Diese ZIP-Datei enthält eine installierbare Progressive Web App (PWA).

WICHTIG:
Eine PWA kann auf iPhone/iPad nur über eine sichere HTTPS-Webadresse installiert werden.
Die Dateien allein in der Dateien-App reichen nicht für „Zum Home-Bildschirm“.

So geht es:
1. Lade diese ZIP-Datei auf einen Computer herunter und entpacke sie.
2. Lade den Inhalt des Ordners heimtraining_pwa auf einen HTTPS-Webhost hoch (z.B. GitHub Pages).
3. Öffne danach die veröffentlichte HTTPS-Adresse in Safari auf dem iPhone.
4. Tippe auf Teilen > Zum Home-Bildschirm > Hinzufügen.

Die App speichert den Trainingsfortschritt lokal im Browser auf diesem Gerät.
